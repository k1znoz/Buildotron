# Validation rapide — FAQ

1. Ouvrir `projects/product-landing.json` dans le Builder, puis ajouter FAQ depuis la Library.
2. Sélectionner FAQ et remplacer la première question et sa réponse dans l'Inspector. Le Canvas doit afficher la nouvelle question.
3. Cliquer sur la question dans le Canvas : la réponse doit s'ouvrir. La touche Entrée ou Espace doit faire de même quand la question a le focus.
4. Ajouter une deuxième question, la renseigner, puis la retirer. Il doit toujours rester au moins une question.
5. Dupliquer FAQ, modifier une réponse dans la copie et vérifier que l'original reste inchangé.
6. Enregistrer le JSON, le rouvrir et vérifier les questions, les réponses et leur ordre.
7. Vider une question ou une réponse et tenter d'enregistrer : la sauvegarde doit être refusée.

Un ancien projet JSON contenant une FAQ sans liste de questions reste ouvrable ; le Builder lui attribue une question par défaut.
