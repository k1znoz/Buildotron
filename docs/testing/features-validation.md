# Validation rapide — Features

1. Ouvrir `projects/product-landing.json` dans le Builder et sélectionner Features.
2. Modifier le titre et le texte du premier élément ; vérifier que la carte du Canvas change immédiatement.
3. Ajouter un élément, renseigner son titre et son texte, puis en retirer un. Le Canvas doit suivre la liste sans carte « Feature 1/2/3 » fictive.
4. Dupliquer Features, modifier un élément de la copie et vérifier que l'original reste inchangé.
5. Enregistrer le JSON, le rouvrir et vérifier que la liste et son ordre sont conservés.
6. Vider le titre ou le texte d'un élément et tenter d'enregistrer : la sauvegarde doit être refusée. Rétablir une valeur avant de sauvegarder.
7. Vider le titre ou le texte de la section Features elle-même, puis tenter d'enregistrer : la sauvegarde doit aussi être refusée. La même règle s'applique aux autres sections.

Les anciens projets sans liste Features restent ouvrables avec trois éléments par défaut.
