# Validation rapide — vignettes de la Library

1. Ouvrir le Builder. Dans la Library, vérifier qu'une vignette différente apparaît pour Hero, Features, Gallery, FAQ, CTA et Footer. Navbar possède aussi une vignette.
2. Utiliser Tab pour placer le focus sur un bouton de section. Son nom doit rester lisible et le contour de focus visible.
3. Appuyer sur Entrée ou Espace pour ajouter Hero. La section doit apparaître dans le Canvas comme avant.
4. Répéter avec Gallery ou FAQ, puis contrôler que le type sélectionné dans l'Inspector correspond au bouton choisi.

Les vignettes sont des repères visuels ; le nom du bouton reste la source de son intitulé accessible.
