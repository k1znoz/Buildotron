# SEO System

## Objectif

Le SEO est une fonctionnalité native de Buildotron.

Le développeur renseigne les bonnes informations.
Buildotron génère automatiquement le reste.

## Génération automatique

À chaque export :

- title
- meta description
- canonical
- OpenGraph
- Twitter Card
- robots.txt
- sitemap.xml
- favicon

## SEO des composants

Chaque composant connaît son rôle.

Exemples :

- Hero → H1
- Features → H2
- FAQ → FAQ Schema
- Product → Product Schema

## SEO Report

Avant l'export, Buildotron vérifie :

- H1 unique
- Meta description
- Alt des images
- OpenGraph
- Schema.org
